\section{Sobol Sensitivity Details (Tables S3--S5)}

Table~\ref{tab:sobol_chain}--\ref{tab:sobol_rgg} report the full first-order ($S_1$) and total-order ($S_T$) Sobol indices with 95\% confidence intervals for each topology. All $S_1$ confidence intervals include zero, and all $S_T$ values are near 1.0, indicating that the Saltelli estimator has not converged (see noise-floor diagnosis in the main text).

\textbf{Note on point-estimate--CI consistency:} For several parameters with non-negligible $S_1$ (retrieval efficiency, $T_2$, $t_{\rm attempt}$), the point estimate lies outside the reported 95\% confidence interval (e.g., chain retrieval efficiency: $S_1 = 0.232$ with CI $[-0.103, 0.104]$). Similarly, several $S_T$ point estimates fall below their CI lower bounds (e.g., chain retrieval efficiency: $S_T = 0.785$ with CI $[0.863, 1.149]$). This is a further symptom of Saltelli-estimator non-convergence: the bootstrap confidence intervals are computed from the same limited sample and do not reliably bracket the point estimates when the estimator has not converged. These results should not be interpreted as quantitative variance-attribution values; the permutation-importance cross-check in the main text provides a more stable qualitative ranking.
